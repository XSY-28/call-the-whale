# 发现、启动与 Codex 浏览器

## 发现优先于启动

1. 若可用，先调用 `mcp__codex_app__read_thread_terminal`。它只读当前任务的 app terminal；“未附带终端”不意味着没有 dsh。另一个 `exec_command` 的运行会话只能用其返回的 `session_id` 继续读取。
2. 用 `mcp__cua_repl.js` 的当前文档列出内置浏览器和标签页。第一次调用遵守该工具初始化规则，例如仅 `await cua.getState()`。复用匹配服务的标签页，不能把系统浏览器标签当作右侧内置页面。
3. 必要时按操作系统和已安装工具检查进程/监听。macOS 上若有 `lsof`，可用 `lsof -nP -iTCP -sTCP:LISTEN`，对候选 PID 用 `lsof -p <PID> -a -d cwd,txt,1,2 -Fn` 核对归属。其他系统先核对其工具文档，不把 macOS 参数直接照搬；缺少命令时继续使用终端输出和标签页证据，证据不足则报告。不要扫描环境变量或整份进程参数找密钥。沙箱限制不等于服务故障。
4. 候选须满足：确实是 dsh、服务启动完成、页面认证有效、可读取会话/workspace 并响应操作。端口开放、HTTP 200、进程名、标题或静态页面单独都不够；只打开模式用不调用模型的导航验证交互。
5. 有多个候选时按项目、profile、现有会话及认证状态选择。网页不通先诊断。尚未排除一个正在运行的服务前，不重复启动；若运行但认证 URL 遗失，优先已有认证标签或原启动输出，不为了取 token 杀掉用户任务。

## 无可用服务时

先确定 Node/npx、本机实际解析的 dsh 包与版本；有缓存/源码时检查该安装的 `package.json`、帮助和 README。不要把 `@latest` 更新变成启动前提。

开发任务先按 [项目选择规则](projects.md) 确认目标，在该目录通过可保持运行会话的终端执行当前版本支持的命令。只打开且没有目标项目时，优先复用服务；确需启动可用系统临时目录 API（例如 Python `tempfile.mkdtemp`）创建私有临时目录作为 cwd，无须先设置默认项目，不硬编码某个平台的临时路径。该临时目录只用于启动，不注册为任务项目、不保存为默认值、不提交任务；服务停止前不清理它。

```sh
npx @deepseek-ai/dsh web --no-open
```

`exec_command` 支持 `workdir`、PTY 和持续会话；使用返回的 id 读取增量输出。不假定它等同于用户可见的 app terminal，也不假定关闭任务后进程必然存活。需要用户可接管的终端时，用当前工具真实支持的方式打开，不能混用不兼容的 session id。

- 等到实际就绪输出，取它打印的完整地址，包括当次认证信息；不要写死端口或从默认值反推地址。
- `--no-open` 防止另开系统浏览器；不能省略后再用关闭浏览器补救。
- 需要复用缓存时先核对当前 npm 是否支持 offline 及是否有目标版本缓存，不冒充安装完成。首次获取官方 npm 包按当前任务授权和权限执行；不能自动升级来排错。
- 部分版本运行帮助也可能准备/写入 profile。无污染核对用系统创建的临时目录作为独立 `DSH_HOME`，只运行帮助，不复制用户密钥或配置。
- launcher/app 参数顺序依当前版本帮助与官方 CLI 参考确认。仅在已核实兼容、允许调整服务且无活动任务时使用临时 overlay；不默认应用历史补丁。
- 端口冲突先确认占用者；只有确有需要且当前帮助支持时使用动态端口参数，仍以输出地址为准。

## 打开与交互

以下是已使用过的 Codex 工具名称示例，不保证所有安装均提供。调用前读取当前实际工具 schema；同等能力工具遵守其文档，不能把下面的名字当作工具发现结果：

| 工作 | 工具/能力 |
|---|---|
| 读当前 app terminal | `mcp__codex_app__read_thread_terminal` |
| 执行/跟进终端命令 | `exec_command` / `write_stdin` |
| 在 Codex 右侧展示 | `mcp__codex_app__open_in_codex`，`placement: "right"`，browser target；queued 仅代表已排队 |
| 查找、打开、操作内置网页 | `mcp__cua_repl.js`；`cua.getState`、`getTab`、`createBrowserTab("iab", actualUrl, {visible:true})`，然后读取 AX 状态 |

已有标签先 `getTab`；新标签创建和 `open_in_codex` 不要各创建一份页面。展示已有 tab 时使用工具返回并验证过的 id。UI 返回 queued 时以实际标签状态确认，不报告为已经显示。

每次操作基于新 AX/DOM/screenshot；按钮名随语言/版本变化。不要保存 AX 数字、猜 CSS 或调用未文档化 RPC。打开面板不是读取页面；不要用外部 Playwright、浏览器数据库或配置文件修改代替网页交互。

认证 URL 在本地服务交换 Cookie 后通常转到干净根地址。只在运行内存/受控工具输入中使用它，报告只写凭据已确认或缺失。不要复制 raw terminal 到交付物。

## Workspace、会话、模型检查

启动 cwd、workspace 名称、会话实际路径可能不同。目标来自当前明确指定、本机默认配置或已确认的原会话，按 [项目选择规则](projects.md) 决定；网页上次选择不参与默认值推断。通过页面可见路径、workspace 详情/目录选择器和项目文件核实完整路径；同名目录不能仅凭名称提交。恢复时保留原会话项目，用户新指定路径与它冲突则先澄清，不在该会话发送可写任务。

创建任务前检查目标会话、agent preset、提供方/模型和非敏感可用状态，并按下面规则核验权限与推理等级。未完成首次配置、缺凭据或认证失败时，提示用户自行回到 dsh 配置并成功获得回复后继续；不输出凭据、不要求粘贴 key、不提取其他软件凭据。只打开不调用模型测试；开发时首个必要任务自然验证连接，不凭模型名称可见就宣称接口可用。不因调整推理等级更换模型/提供方或保存新凭据。

### 会话权限与推理等级

检查时机：打开/恢复目标会话后、**每次新建会话后**、每次提交前；切换模型后还要重新检查推理等级。用户当前任务指定的推理等级优先于 High 默认值，并沿用到该任务的新会话、恢复和修正阶段。先读当前值，已经符合目标就不重复切换。

**权限目标：完全访问权限。** 已核对的 dsh `0.1.5-rc.2` 显示“完全权限”/“Full access”，对应默认 preset `danger-full-access`，组合不受项目目录约束的 sandbox 模式和 `never` 审批策略。自定义 preset 可变，运行时核对真实语义，不只看名字。它不绕过操作系统权限；实际范围取决于 dsh 配置、运行账户和系统限制。通过会话访问控件或当前支持的 `/permission` 选择器切换，以宿主回显确认，不猜选择器或后台参数。

首次需要启用前告知用户可能读写本机文件、执行终端命令和访问网络，并取得覆盖当前任务的授权；安装、阅读 README 或仅说“打开 dsh”本身不等于授权扩大权限。已有有效授权不反复询问，但网页风险确认及工具当次确认仍必须遵守；若需要当次确认，解释具体来源与影响，不能用 CLI、配置文件或其他界面绕过。权限未授权时保留已打开页面，暂停依赖该权限的开发提交。完全访问仍只允许任务范围内操作，保护已有修改，不删除无关文件、不发布其他项目或操作其他账户。

通用设置中的权限默认值只影响之后创建的会话，不会修改当前会话。优先检查和调整目标会话，无需为了实现该行为顺带修改全局设置。每个新会话创建完成后再核验一次，即使上个会话或全局默认值已是完全权限。若只有草稿且控件尚不可用，不为“只打开”强行创建开发任务；说明状态未确认，并在实际创建会话后、首条开发消息前完成检查。

**推理目标：用户指定等级，否则 High。** 从当前模型控件查看真实可选等级，通过 UI 选择目标值，核对当前会话回显。切换模型可能应用模型自身默认等级，因此必须在模型确定后再核验；不可仅在任务提示词里写“请使用 High”代替实际设置。

已核对版本的模型选择作用于下一次请求，运行中的步骤保留启动时设置；后续版本需复核。用户在执行中改等级时，保留已接受任务，按当前 UI 支持的控制方式让后续请求生效；不要重发整个开发任务或声称已影响正在运行的步骤。

模型没有目标等级、未提供推理控件或设置无法确认时，说明当前模型支持的选项和具体缺口，不静默选其他等级、不擅自换模型。需要用户决定的替代方案保持待定；只打开仍可交付已打开页面，并说明未完成的设置，开发任务在解决影响执行的设置缺口后再提交。

### 原生目录选择器不可操作

先确认是原生对话框/选择器问题，不能绕过工具禁止控制的应用。官方 directory-picker-browse 提供网页选择能力，但须按当前版本核对 host/client 包、依赖、启用方式和实际 UI，不复用历史行 id。只在自己拥有、无活动任务且获准调整的服务使用临时 overlay；已有服务先评估任务状态、恢复能力和配置授权。没有受支持替代时报告 workspace 选择受阻，保留已打开页面。官方来源见 [兼容性参考](compatibility.md)。
