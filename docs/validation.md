# 验证范围

公开版采用独立目录和干净 Git 历史，只包含维护所需的技能、脚本、测试与说明。原开发环境的完整日志、私人路径、配置、截图和历史报告不进入仓库。

## 可重复的检查

- Python unittest：目录选择、独立默认配置、token 故障分类、退避/停止条件、交接/防重复、安装更新/卸载及配置保留。
- 隔离 Git 项目：真实后台进程停写、实际 diff、私有交接文件落盘、只补剩余功能并独立验收；提供方错误和会话为模拟。
- Node 隔离样例：clamp 实际产物的独立断言与测试，不启动 dsh 或调用模型。
- 静态包检查：技术标识、品牌元数据、相对链接、公开文件范围及常见私密路径/凭据模式。发布前另人工检查待推送文件、完整新历史和提交元数据。
- 安装维护：使用临时 CODEX_HOME/安装目录，检查官方 skill-installer 的仓库子目录安装方式；维护脚本只更新/卸载 dsh-dev，保留默认配置和交接，旧技能单独备份。

CI 的 Linux/macOS 结果仅适用于以上无模型测试，不证明这些系统具备完整 Codex 桌面浏览器工作流。

## 历史真实操作与本次发布的区别

此前在 macOS 的 Codex 内置浏览器完成过一个隔离小函数任务：发现/启动与复用服务、选择正确 workspace、提交、独立验收、故障注入后定点修复及刷新恢复。仓库保留通用化的最终 clamp 样例；执行验收脚本只复测产物，不重放那个网页流程。

公开版移除了作者的固定路径、个人模型/插件清单、历史进程/会话标识和用户专属授权假设。初版开发权限要求为 Full access；变化是首次面对新用户必须说明风险并核对其有效授权。当前规则进一步限定：纯聊天和只打开不自动提权，开发默认完全访问，用户明确的任务权限配置优先。安装不修改 dsh 全局权限；默认项目仍由每个用户独立设置。原有任务委托、插件选择、按需调研、模式选择、纠正与恢复职责没有删除。

已核对 dsh `0.1.5-rc.2` 的权限、模型选择、压缩及内部重试代码/官方文档；这些是接口与版本检查，不是本次真实权限切换或故障恢复的证明。

## 未验证范围

未验证 Windows；POSIX 文件权限接口不保证 Windows 可用。没有宣称 Linux/其他客户端的完整桌面流程可用。未为本次发布触发真实上下文/输出上限、限流或余额耗尽；未对 workflow、Teams、插件安装/回滚、备用提供方切换或持续后台执行做完整端到端测试。

脚本接收的 UI/会话状态是 Codex 已核实的观察，不能代替实际浏览器、任务运行状态和文件检查。缺少首次配置或权限授权只做模拟场景审阅；不会为了测试收集 API key。

发布后可结合本仓库 CI 和 Release 记录确认对应版本的执行结果；失败或跳过不得被记成端到端通过。
